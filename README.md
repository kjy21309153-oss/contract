# 조달계약 검토 도우미 — 초심자용 배포 가이드

컴퓨터에 아무것도 설치하지 않고, 브라우저만으로 실제 작동하는 웹페이지를 만드는 순서입니다.
전체 소요 시간: 약 20~30분.

---

## 1단계. 무료 Gemini API 키 발급 (5분)

1. https://aistudio.google.com 접속 → 구글 계정으로 로그인
2. 좌측 메뉴에서 **Get API key** 클릭
3. **Create API key** 클릭 → 발급된 키를 메모장에 복사해둡니다.
   (2026년 기준 Gemini Flash 계열 모델은 하루 1,500회까지 무료입니다. 카드 등록 불필요.)

주의: 무료 티어는 입력한 내용이 구글의 모델 개선에 사용될 수 있습니다.
실제 계약서 원문 등 민감한 문서는 프로토타입 검증 단계에서는 넣지 말고,
공개된 법령·일반 규정 위주로 테스트하는 걸 권장합니다.

---

## 2단계. GitHub에 코드 올리기 (10분, 설치 없음)

1. https://github.com 접속 → 계정이 없다면 무료 가입
2. 우측 상단 **+** → **New repository** 클릭
3. Repository name에 `contract-ai` 입력 → **Create repository**
4. 방금 만든 저장소 페이지에서 **Add file → Upload files** 클릭
5. 이 대화에서 받은 `app.py`, `requirements.txt` 두 파일을 그대로 드래그해서 올리기
6. 하단 **Commit changes** 클릭

이 과정은 전부 웹브라우저 안에서 이루어지며, 컴퓨터에 아무것도 설치하지 않습니다.

---

## 3단계. Streamlit Community Cloud에 배포 (5분)

1. https://share.streamlit.io 접속 → **Sign in with GitHub**로 로그인
2. **Create app** → **From existing repo** 선택
3. 방금 만든 `contract-ai` 저장소, `app.py` 파일 선택
4. **Advanced settings** 클릭 → **Secrets** 칸에 아래처럼 입력

   ```
   GEMINI_API_KEY = "여기에_1단계에서_복사한_키_붙여넣기"
   ```

5. **Deploy** 클릭 → 1~2분 후 `https://XXXX.streamlit.app` 형태의 주소가 생성되면 완료

이제 이 주소로 접속하면 누구나(링크를 아는 사람은) 브라우저에서 바로 사용할 수 있는
계약 검토 챗봇이 완성됩니다.

---

## 화면 사용법

- **좌측 상단**: 법령·규정·표준품셈 PDF를 올리는 곳 (지식창고). 이름 옆 🔄 버튼은
  "이 문서 최신본으로 바꿔주세요"라는 표시이며, 현재는 재업로드를 안내합니다.
- **좌측 하단**: `➕ 새 대화`와 지난 대화 목록. ChatGPT처럼 여러 건을 동시에 다룰 수 있습니다.
- **가운데**: 문서를 올리거나 질문을 입력하면, 지식창고 내용을 근거로 답하고
  이후 질문에도 이전 맥락을 이어서 답합니다.

---

## 지식창고에 없는 법령은 인터넷 검색으로 보완

지식창고(업로드한 문서)에서 근거를 못 찾으면, AI가 Google 검색으로 최신 법령을
찾아본 뒤 "(인터넷 검색 근거: OOOO년 OO월 개정 OOO법 제O조 참고)" 형식으로
표시합니다. 지식창고 근거와 인터넷 검색 근거는 답변 안에서 구분되어 나옵니다.

⚠️ 이 기능은 일반 답변(하루 1,500회)과 **별도의 무료 한도**가 있습니다.
한 달에 5,000건까지 무료이고, 그 이상은 유료입니다. 사용량이 많아지면
Google AI Studio에서 사용량을 확인해보세요.

## 다음 단계로 확장하려면

- **법령 자동 업데이트 붙이기**: 법제처(law.go.kr)에서 Open API 키를 별도 신청하면,
  `app.py`의 `refresh_document()` 함수 안에서 법령명으로 API를 호출해
  공포일자를 비교하고 자동으로 지식창고를 교체하도록 만들 수 있습니다.
  (신청: https://open.law.go.kr → 회원가입 → API 활용신청)
- **더 똑똑한 검색**: 지금은 TF-IDF라는 간단한 방식으로 관련 문서를 찾는데,
  문서량이 많아지면 임베딩 기반 벡터 검색(Chroma 등)으로 바꾸면 정확도가 올라갑니다.
- **사내망 전용 배포**: 실제 계약서 등 민감 문서를 다루려면 이 무료 클라우드 대신
  사내 서버에 올려야 합니다. 이 단계는 IT/보안 부서와 협의가 필요합니다.
